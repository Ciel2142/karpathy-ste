What is a sheet made of?

templates/sheet.html
  • sheet.html
    • .sheet fixed 1920 x 1080 canvas, frame
      • .grid 12 columns x 2 rows
        • section.panel A to F, one question each
          • header.panel-head tag, title, caption
          • div.panel-body one primitive
        • aside.title-block title, keys, provenance
    • <style> palette, type, six primitives
    • <script> guard: measures, writes data-verify

One file, no remote partsThe sheet opens offline from one file. Send it as a file or as a PNG.

         id="panel-C">
  <header class="panel-head">
    <span class="tag">C</span>
    <h2>Which checks run?</h2>
    <span class="caption">verify.sh</span>
  </header>
  <div class="panel-body">
    <!-- one primitive -->
  </div>
</section>
1
The span class sets the panel width in grid columns. A row has 12 columns.
2
The id gives the panel letter. The guard uses this letter in its report.
3
The title is the one question that the panel answers.
4
The caption shows the source or the scope of the panel.
5
Put one primitive in the body. Write at most 250 words.

How does a sheet get to the reader?

build sequence
  1. Copycptemplate to out/
  2. Fillindex.htmlpanels, title block
  3. Verifyverify.shfour checks
  4. Exportsnapshot.shPNG and 4 tiles
  5. Reviewreview/read each tile
  6. Hand offopenprint the path

What the guard doesThe guard script runs one time when the page loads. It measures each panel, the page and the smallest text. It writes OK or the list of failures into data-verify on the html element. A red ribbon marks each panel that overflows.

If verify.sh fails, fix the sheet. Then run the two scripts again.
